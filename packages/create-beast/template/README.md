# __PROJECT_NAME__

A [Beast](https://www.npmjs.com/package/beast-tsrx) project powered by
[TSRX](https://tsrx.dev/) and [Octane](https://octanejs.dev/).

```bash
bun install
bun run dev
```

Edit `src/App.btsx` to get started. The Beast Vite plugin compiles BTSX into
native TSRX and then lets Octane produce the browser module.
